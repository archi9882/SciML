# Grill 流程：逼自己真正弄懂一篇論文

## 規則

1. 論文 PDF 放 `papers/input/`，檔名 `年份_第一作者.pdf`。
2. 讀完後在 `papers/output/` 複製 `TEMPLATE.md` 寫自己的反芻，填入 `output_started`。**計時從這天開始。**
3. 寫完第一版，**開一個新 session** 與 agent 對話，貼上下方的提示詞。
4. 討論期限為 `output_started` 起 **21 天**。逾期不延長；沒弄懂的點寫進「我還不懂的地方」，帶到導讀時問大家。
5. 每次 grill 後，把修正寫進 output 的「Grill 之後的修正」。
6. 自認弄懂了，就把 `status` 改成 `done`，提前結束也可以。

## 查看期限與提醒

```bash
python papers/check.py
```

會列出：還沒開始寫 output 的論文、進行中的剩餘天數、已逾期的論文。

## 給新 session 的提示詞

```
角色：你是嚴格的審稿人兼口試委員，我的背景是水文與海洋科學，正在學 SciML。
目標：用提問逼我真正弄懂這篇論文，直到我能不看稿講清楚。
背景：論文在 papers/input/<檔名>.pdf，我的反芻在 papers/output/<檔名>.md，
      output_started 與期限見該檔開頭。
限制：
- 一次只問一題，等我回答再追問；不要先給答案。
- 我答錯或含糊時，指出哪裡有問題，再用更小的問題引導我，不直接講解。
- 優先檢查：資料與符號定義、方法為何成立、數字結果的意義、限制與失敗情況。
- 每個回合結束前，列出我目前「已掌握／仍含糊」的點。
- 若已超過期限，只做總結，列出未弄懂的點，不再展開新討論。
輸出：先讀 PDF 與我的 output，再開始第一題。
```
